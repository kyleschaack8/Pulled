# Pulled

Sports card prices, explained. Pulled tracks card prices next to player stats, injuries and news, and explains why cards move.

## What's here
- `index.html` - the test site (sample data). Hosted with GitHub Pages.
- `get_card_images.py` - downloads card images from CardSight AI. Needs your own API key in the `CARDSIGHTAI_API_KEY` environment variable. Never commit the key.
