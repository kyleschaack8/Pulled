# Design mockups

Source files for the Pulled design canvas: four screens designed in Claude.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Player page (Stephen Curry example) with the combined card trend |
| `Card.dc.html` | Card page with the price vs. performance chart |
| `Compare.dc.html` | Compare cards: price, sales volume, graded population |
| `Website.dc.html` | Marketing landing page |
| `canvas.json` | Canvas layout |

These files use Claude's design-canvas format, so they don't open as normal web pages. View and edit them on the canvas in Claude. The landing page is also available as a normal web page in [`/landing`](../../landing/index.html), and the working app is the site's main `index.html`.

All numbers in the mockups are sample data.
